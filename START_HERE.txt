🔄 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. User visits app
   → Redirected to /login if not authenticated

2. User signs up
   → Form validation checks all fields
   → Submits to backend /api/auth/signup
   → Backend creates user, returns token
   → Token stored in localStorage
   → Redirected to home page

3. User sees personalized home
   → "Welcome back, John!" greeting
   → Can access protected pages
   → Token automatically sent with API requests

4. User clicks logout
   → Token removed from localStorage
   → Redirected to login page
   → All protected routes blocked again

5. User refreshes page
   → Token still in localStorage
   → User stays logged in
   → Session persists!
